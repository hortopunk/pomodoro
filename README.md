# 🍅 Pomodoro

Minuteur Pomodoro minimaliste pour smartphone Android. Un rectangle rouge progresse sur tout l'écran pour illustrer le temps qui passe, avec le temps restant affiché au centre en effet de balayage.

## Fonctionnalités

- ⏱️ Minuteur configurable (1 à 120 minutes)
- 🔴 Barre de progression rouge plein écran
- ✨ Effet de balayage sur le texte (rouge → blanc)
- 🔒 Écran toujours allumé (Wake Lock API)
- 📱 Mode paysage + plein écran automatique
- 📲 Installable comme app (PWA)
- 📳 Vibration à la fin
- 🎨 Police Montserrat, design ultra minimaliste
